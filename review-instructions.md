# Task for AI

**Цель** — подготовить предложения по рефакторингу кода по следующим критериям:

1. мёртвый код;
2. дублирование: обработчиков и логики. Не всё похожее нужно объединять, но каждое решение нужно обосновать;
3. имена, которые не читаются без комментариев;
4. комментарии, которые пересказывают код;
5. функции, которые не читаются целиком.

Классический источник по теме — книга Роберта Мартина «Чистый код». При выявлении проблем руководствоваться общими принципами, указанными в данной книге.

**Границы** — проверить предоставленные файлы, не вносить в них никаких изменений.

**Критерий готовности** — все указанные проблемы обнаружены и помещены в отчёт.

**Формат вывода** — отчёт в файле `review-report.md` на русском языке, замечания сгруппированы по категориям из задания. Каждое замечание состоит из четырёх частей:

1. место в коде (название функции и номер строки в файле);
2. проблема кратко в одном предложении;
3. условие, при котором она проявляется, например при каком-то действии пользователя;
4. способ проверить исправление.
